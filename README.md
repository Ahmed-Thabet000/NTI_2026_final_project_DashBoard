About the Project

This project is an e-commerce administration dashboard developed collaboratively by a team using **native PHP** and the **MVP (Model-View-Presenter) architectural pattern**.

Unlike the individual ANALAGIA project, this project focuses exclusively on the administration dashboard and does not include a public-facing landing page.

I served as the **Team Leader**, coordinating team contributions and managing code integration through Git and GitHub.

Features

- **Administration Dashboard:** Interface for managing e-commerce data.
- **MVP Architecture:** Separate application responsibilities using the Model-View-Presenter pattern.
- **Native PHP:** Built with PHP without a web application framework.
- **Responsive UI:** Dashboard interface developed using HTML, CSS, and Bootstrap.
- **Team Collaboration:** Shared development through Git and GitHub.
- **Code Integration:** Pulling team updates, reviewing contributions, and merging pull requests.

Technologies Used

- **Backend:** Native PHP
- **Architecture:** MVP (Model-View-Presenter)
- **Frontend:** HTML, CSS, Bootstrap
- **Version Control:** Git, GitHub

My Role — Team Leader

My responsibilities included:

Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Ahmed-Thabet000/NTI_2026_final_project_DashBoard.git
   ```

2. Navigate to the project directory:

   ```bash
   cd NTI_2026_final_project_DashBoard
   ```

3. Set up a local PHP environment, such as XAMPP, compatible with the project.

4. Configure the database using the database file and instructions provided in the repository, if applicable.

5. Update the database connection settings to match your local environment.

6. Run the application using your local web server and follow any project-specific setup instructions.
